# Страница мини-приложения для спайка

Статическая страница без бэкенда. Показывает стартовые параметры так, как их
прислал MAX, и даёт кнопку копирования. Подпись проверяется локально:

    python3 selftest.py --launch "вставленная строка"

## Почему без сервера

Чтобы проверить подпись на сервере, нужен токен бота. Класть токен в
страницу, которую открывает пользователь, нельзя ни при каких условиях —
он утечёт с первым же просмотром исходного кода. Поэтому страница только
показывает данные, а проверка идёт на машине разработчика.

Второй довод: бесплатные быстрые туннели выдают новый адрес при каждом
перезапуске, а адрес мини-приложения привязывается к боту в панели.
Статический хостинг даёт постоянный адрес — привязать нужно один раз.

Версия с сервером и автоматической проверкой лежит в `maxspike/miniapp.py`;
она пригодится, когда появится постоянный бэкенд.

## Что страница отвечает

Главный открытый вопрос спайка — как MAX кодирует значения в строке.
Страница показывает наличие незакодированного `+` и пробелов в виде `%20`:
от этого зависит, каким декодером собирать строку для подписи.

## Публикация

Любой статический хостинг с https: GitHub Pages, Yandex Cloud, VK Cloud.
Полученный адрес привязывается к боту в панели business.max.ru.

Страница закрыта от индексации мета-тегом `robots: noindex,nofollow`.
